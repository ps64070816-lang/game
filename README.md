# 🎴 LAS VEGAS GO-STOP — 라스베가스 고스톱

라스베가스 카지노 분위기의 **고스톱(3인) / 맞고(2인)** 브라우저 게임입니다.
**하수 → 중수 → 고수** 3등급 AI 테이블을 차례로 정복해 라스베가스 고스톱 챔피언이 되세요.
(이전 버전인 텍사스 홀덤 포커는 [`poker/`](poker/) 에 그대로 남아 있습니다.)

## ▶ 실행 방법

| 방법 | 설명 |
|---|---|
| **1. 바로 실행** | `index.html` 더블클릭 → 브라우저에서 바로 플레이 (설치 불필요) |
| **2. 로컬 서버** | `start.bat` 또는 `python server.py` → `http://localhost:8765` |
| **3. 온라인** | https://ps64070816-lang.github.io/game/ |

> 첫 화면을 클릭하면 BGM·효과음·한국어 음성이 켜집니다. (브라우저 자동재생 정책)

## 🎴 규칙 (현행 고스톱)

- **3인 고스톱**(손패 7장·바닥 6장, **3점** 나기) / **2인 맞고**(손패 10장·바닥 8장, **7점** 나기) — 진행은 반시계 방향, 이긴 사람이 다음 판 선
- 족보: 광(3광 3점·비광 포함 2점·4광 4점·5광 15점), 고도리 5점, 홍단·청단·초단 각 3점, 열끗/띠 5장부터, 피 10장부터 (쌍피 2장, 국진은 유리하게 자동 계산)
- 쪽 · 뻑 · 따닥 · 뻑 먹기(자뻑 2장) · 싹쓸이 · 폭탄 → 상대 피 뺏기, **3뻑**·**총통** 즉시 승리
- 고: 1고 +1, 2고 +2, 3고부터 +3점에 ×2·×4…, 흔들기·폭탄 ×2
- **피박**(3인 5장/맞고 7장 이하) · **광박** · **멍박** ×2, **고박**(고 외친 뒤 남이 나면 독박), **나가리** 다음 판 ×2
- 판돈 5만 원으로 시작해 **두 배(10만 원)** 를 만들거나 상대를 모두 파산시키면 스테이지 클리어. 3인 중 한 명이 파산하면 자동으로 맞고로 전환

> 고스톱은 지역·모임마다 세부 룰이 다릅니다. 이 게임은 위의 가장 널리 쓰이는 규칙을 기준으로 합니다.

## 🤖 AI 등급

| 등급 | 무대 | 점당 | 스타일 |
|---|---|---|---|
| **하수** | FREMONT STREET | 500원 | 먹을 게 보이면 대충 먹고, 고를 남발 |
| **중수** | THE STRIP | 1,000원 | 광·고도리·단 가치 계산, 뻑 확률 회피, 상대 점수를 보고 고/스톱 |
| **고수** | HIGH ROLLER ROOM | 2,000원 | 카드 카운팅으로 쪽·뻑·따닥 확률 계산, 상대 족보 끊기, 확정 먹이 아껴두기, **남은 판을 40번 시뮬레이션해 고/스톱 결정** |

헤드리스 시뮬레이션(맞고 3,000판): 고수가 중수에게 +12,970점, 중수가 하수에게 +18,117점. 3인전에서도 고수 > 중수 > 하수.

고도리·홍단·청단·초단·삼광/사광/오광·멍따 달성, 쪽·뻑·따닥·싹쓸이·폭탄·흔들기, 원고·투고·**쓰리고**, 스톱, 피박/광박/고박, 나가리, 총통·쓰리뻑(슬롯머신 잭팟) — 네온 배너, 불꽃놀이, 코인 레인, 캐릭터 대사와 한국어 음성.

모두 **Web Audio API로 실시간 합성**(음원 파일 없음). 가야금·대금·장구를 합성해
하수(굿거리 장단) · 중수(세마치 장단) · 고수(진양조) BGM, 로비(라스베가스 라운지 재즈), 고 2번 이상(긴장감), 승리·게임오버 곡이 상황에 따라 바뀝니다. 화투 치는 "탁!" 소리도 합성입니다.
